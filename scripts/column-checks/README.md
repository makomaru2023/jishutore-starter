# コラム公開前の機械検査3種

編集ガイド（`自主トレ素材庫-workspace/guides/column-editorial-guide.md` §6-2）の検査を、
毎回書き直さずに済むようにスクリプト化したもの。**公開する日に必ず回す。**

★2026-08-28にリポジトリへ移した。それまでは毎回その場で書き直していて、
セッションをまたぐと消えていた。

## 使い方

先に `npm run build` を通してから、生成されたHTMLに対して回す。

```bash
npm run build
python3 scripts/column-checks/kensa1.py .next/server/app/column/<slug>.html
python3 scripts/column-checks/kensa2.py .next/server/app/column/<slug>.html
python3 scripts/column-checks/kensa3.py public/column/<figure>.svg
python3 scripts/column-checks/kensa4-chars.py <変更したファイル...>
```

## それぞれが見るもの

| # | 何を見るか | 落ちたときの直し方 |
|---|---|---|
| 1 | **有料層の書き写し**。`records`/`auditPoints`/`pitfalls` の12文字n-gramのうち、無料層（`requirements`+`units`+`name`）に無いものが記事に出ていないか | ★**ヒット数で判定しない。** 1件ずつ出典を確かめる。同じ加算を同じ語彙で書く以上ノイズは必ず出る。★**自分の表記がたまたま有料層と一致しただけ**のこともあるので、その場合は無料層の言い方に寄せる |
| 2 | **トーン**。一文80字超と語尾3連続 | 語尾を「です／ません／でしょう」等に散らす |
| 3 | **図解のはみ出し**。文字が枠から出ていないか、画面外に出ていないか | ★囲み枠は「文字の中心を横方向に含む rect」から選ぶ（y座標だけで決めると段組みで誤検知する） |
| 4 | **非日本語文字の混入**。キリル・ハングル等 | 走査で出た文字をそのままコピーして置換する |

## ⚠★★ 検査1の穴：description は本文検査では拾えない（2026-09-02）

★**`description` は「関連記事カード」として他ページのHTMLに出る。**
記事本体のHTMLには本文しか入らないので、★**その記事を検査しても description のヒットは出ない。**

実例：9/2に出した記事の description にあった「栄養マネジメント強化加算**の算定**」
（無料層は「〜**を算定していること**」）が、**翌日の記事を検査したときに初めて出た。**

→ ★**公開日には、その記事だけでなく前日の記事も通すこと。**

```bash
python3 scripts/column-checks/kensa1.py .next/server/app/column/<今日>.html .next/server/app/column/<前日>.html
```

⚠全記事（`.../column/*.html`）に通すこともできるが、既存ぶんのノイズが131件出る（2026-09-02実測）。
**新しい2〜3本に絞るほうが読める。**

## ⚠★ 検査1で出るのは「写した」ではなく「原本からずれた」ことが多い（2026-09-02）

3件とも**有料層を写したのではなく、原本の言い回しを崩した結果、有料層と一致していた。**

| 書いていた | 原本（無料層 requirements）の逐語 |
|---|---|
| 計画の見直し等に活用する**こと** | 活用**していること** |
| 口腔の健康状態**、**栄養状態の情報 | 口腔の健康状態**及び**栄養状態に関する情報 |
| 栄養マネジメント強化加算**の算定** | 栄養マネジメント強化加算**を算定していること** |

→ ★**要件を地の文に溶かすときほど、原本を逐語で引く。** 名詞化（「〜の算定」）が特に危ない。

## ⚠ 検査2の落とし穴（2026-08-23・08-24・08-27に3回踏んだ）

- ★**記事の締めの一文と、共通CTAの2文で「ます」が3連続する**。
  CTAは「〜配布しています。」「〜使えます。」で終わるので、**締めが「ます」だと自動的に3連続**になる。
  → **締めは「です／でしょう／ません／ました」で終える**と決めておくと構造的に消える。
- ★間に `Note` / `H2` / `Figure` が挟まる箇所は、このスクリプトが飛ばすので**誤検知も出る**。
  読者に見える並びで判断すること。

## ⚠ 検査3で毎回ずれるもの

- ★**下書きのaltは図の初期案のまま残っていることが多い**（8/23・8/24に2日連続）。
  公開前に必ずSVGの文言と突き合わせる。
- 記事側の `width`/`height` は**SVGのviewBoxと必ず一致させる**（縦横比が崩れる）。
- 本文に「N項目」と書いたら、**図の枠の数と突き合わせる**（下部の帯を数に含めないこと）。
