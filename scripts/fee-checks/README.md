# 報酬チェックの出典検査（月次）

`checklists/weekly-ops.md`（workspace）の「報酬チェックの改定確認」で毎月回す機械検査。
**制度の新規発出がゼロの月でも、ここは腐る**ので毎月見る。

★2026-09-02にリポジトリへ入れた。それまでは点検のたびにその場で書き直していた。

```bash
python3 scripts/fee-checks/kensa-sources.py              # 3つとも
python3 scripts/fee-checks/kensa-sources.py --links      # 個別に回す
python3 scripts/fee-checks/kensa-sources.py --pages --numbers
```

必要なもの：`pypdf`（`pip3 install --user pypdf`）。
一次資料は `.fee-source-cache/`（gitignore済み）に貯める。初回は5〜10分かかる。
**訂正版が出たときはキャッシュを消す**（同じURLで中身が入れ替わることはないが、
新しく差し替えたURLを取り直すため）。

## 何を見るか

| # | 何を見るか | 落ちたときの直し方 |
|---|---|---|
| 1 `--links` | 出典URLのHTTPステータス | ★**訂正版が出ると旧URLは消える**（2026-08に10か所が404）。ポータルから新しいPDFのURLを取って差し替える |
| 2 `--pages` | 「PDF p.◯」が本当にその条文のページか | 原本を開いて実測ページに直す。★**ページがずれても中身は正しいことが多い**ので、条文そのものを読んでから直す |
| 3 `--numbers` | `units` の点数・単位数が出典本文に実在するか | ★**出ないほうが異常**。出たら点数の写し間違いを疑う（「AIの記憶で点数を書かない」の機械側の担保） |

## ⚠ 出たものは「候補」であって「誤り」ではない

### 検査2でほぼ必ず出る偽陽性（2026-09-02に全件を原本で確認済み・直す必要なし）

**区分番号は節の先頭ページにしか出ない。** 「A308 (11)」のように節の途中を指す参照は、
そのページに区分番号の文字が無いので不一致に出る。

| 参照 | 実際 |
|---|---|
| `chiiki-hokatsu-care-hokatsu-hani` A308-3 注7 p.76 | 注7の本文はp.76。A308-3の見出しはp.73 |
| `kaifukuki-riha-keikakusho-kiroku` 第7部通則 p.490-491 | 通則の見出しはp.489の末尾。本文はp.490-491 |
| `kaifukuki-riha-sogo-keikaku-hyoka` A308(11) p.123 | A308の見出しはp.121 |
| `kaifukuki-riha-eiyo-shido-renkei` A308(15)(16)(18) p.125-126 | 同上 |
| `kaifukuki-riha-sesshoku-enge-kaifuku` A308(13) p.123 | 同上 |

**「範囲の端が空」も多くは正常。** 点数表・計算例・様式など、手がかりの語が無いページを
範囲に含めているだけのことがある（`p.10-13 A100`、`p.74-77 A308-3` など8件は確認済み）。
